# relato-urbano-short

Skill de Claude Code: Shorts promocionales verticales de los reportajes de Relato Urbano, montados con el material del propio reportaje. Instrucciones en `SKILL.md`; reglas de impacto, interacción, puertas y publicación en `references/`; el script `scripts/short.py`; la composición vertical de Remotion en `plantilla/`.

Necesita la skill `relato-urbano-reportaje` instalada al lado (en `~/.claude/skills/`): usa su carpeta de proyectos (`rutas.py`), su voz (`voz_fish.py`), su maestro de audio y el Remotion de cada reportaje.
